<objective>
Lay the Phase 2 event channel: protocol v2, a preallocated event ring in Python, and kill and hit events from the existing drones that cross the boundary every frame. Every later effect, light, wreck, shake and sound is driven by this channel.

Purpose: this is the foundation slice of VISL-03 (particle explosions) and ENMY-08 (flash on hit, explode on destruction). Plan 02-02 is the matching integration slice that turns these events into GPU particles. This plan bumps the protocol to v2 once, with a 48-slot header whose slot numbers are reserved below for the rest of the phase.
Output: protocol v2 constants (header, events channel, event ids, blast classes), EventRing, drone kill and hit events, Game wiring, and the bridge's protocol check, all with tests.
</objective>
